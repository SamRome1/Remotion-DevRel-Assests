name: Animation Sizing Feedback
description: Fill the full canvas, no dead space. Larger nodes, bigger fonts, distributed spacing.
type: feedback
---

Fill the full canvas — no dead space. Use larger nodes, bigger fonts, and distribute elements across the full 1920×1080 (or 1080×1920) canvas.

**Why:** Earlier compositions left large empty margins. The user expects compositions that feel intentional and cinematic, not shrunken in a corner.
**How to apply:** When positioning elements, span the full width and height. Default node radii, font sizes, and card dimensions should be generous. Prefer using the full canvas area over tight central groupings.
